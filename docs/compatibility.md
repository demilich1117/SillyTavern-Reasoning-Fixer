TT 的 ST 兼容层为 1.18.0，不能等同上游 ST 1.18.0。manifest 的 `minimum_client_version: 1.18.0` 是 ST 接口下限，不是 TT 应用版本，也不表示所有后续版本已验收。

## 适配边界

- 通过 context 重新取得聊天和设置，保存走宿主 `saveChat()`；不缓存聊天数组。生成期间延后写入，用消息对象与聊天身份过滤过期任务。
- ST 在正文正则前隔离思考，在 Markdown 后拼接安全显示，宿主继续执行最终 DOMPurify 清理。
- TT 无 MessageFormatter，运行期包装宿主 converter 与 ReasoningHandler，不写核心文件。只推断能唯一匹配当前聊天消息的开头思考包裹；重复原文无法归属时保守跳过。原生思考使用明确的同步范围。
- TT 首次正文正则已发生，适配器丢弃其显示结果并单独重跑正文预处理，无法撤销其他钩子已产生的副作用。正文 CSS 范围与实体后处理只应用一次。
- TT chatSurface 用于设置改变时让显示缓存失效；流式保护由同步格式化适配器完成。不会把最终内容处理器当作流式接口。
- 不创建 iframe、DOM 观察器或后台轮询；冷 swipe 不强行加载。宿主重建 Markdown converter 后继续适配。
- 保留原生思考折叠状态。消息清理器的 `custom-` class 前缀已适配。
- 缺少显示接口时明确提示原因，内容修复仍可用。其他扩展替换相同方法时需要核验加载顺序。

## 已完成

- 49 项 Node 测试通过：修复/档案、代码与注释排除、围栏提取、显示镜像与签名、冷 swipe、工具消息、逐个流式前缀、独立开关、实际宿主格式化与清理钩子、CSS/实体只处理一次。
- Windows Chromium 测试页加载两套宿主摘录、真实 Showdown / DOMPurify 和扩展入口；覆盖延后保存、重复事件、聊天切换、重新挂载、显示模式、手动修复、暂停状态与首页标签保存。
- 桌面 1280px、手机 390px 无横向溢出、无页面未捕获异常；浅色/深色面板与键盘展开折叠检查通过。截图在忽略目录 `output/playwright/`。
- 测试依赖仅用于开发。Showdown 2.1.0 与目标宿主匹配，存在 npm audit 中等风险通报且无可用修复版本；不打包 npm 副本到扩展。运行时使用宿主库，宿主升级后须复核。

## 尚需真实环境验收

没有启动完整 ST 服务或 TT 原生 WebView，没有连接真实模型，也没有完成跨设备、宿主重启持久化与第三方助手 iframe 联合测试。测试页的事件总线、保存、虚拟挂载和正文正则是替身；CSS 范围测试模拟上游非幂等前缀操作。浏览器测试不能证明完整原生宿主兼容。
